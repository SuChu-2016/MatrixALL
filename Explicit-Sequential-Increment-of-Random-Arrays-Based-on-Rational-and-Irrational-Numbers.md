# Calculation of Implicit Phenomena in the Sequential Increment of Random Large Arrays of Irrational Numbers

**Author:** Xin Sun | Mingxin@msn.com

## Abstract

This paper conducts a structured study on the sequential increment phenomenon achieved through overlay calculations of numerical changes in random numbers. It covers, but is not limited to, the random variation of irrational numbers and constants—such as Pi, the natural constant, and the square root of 2. By reconstructing incremental assignments of these irrational numbers, it realizes explicit calculations for both fixed and non-fixed random values, thereby obtaining stepwise incremental results from numerical and array reconstruction. The general formula is expressed as:

```
a1, (a1 + a2 = b1), (b1 + a3 = b2), (b2 + a4 = b3), (b3 + a5 = b4).
```

For instance, the fixed random value of Pi (3.141,592,653,589,793,238,462,643) can be transformed into 3.141,733,1386,1975,2768,3006,3468,4111. Its increments can be merged into aₙ to establish a foundation for reconstruction and achieve operational assignment for sequential increment.

## Background

In various mathematical computations—especially when algorithms within programs process long columns of numbers and arrays—it is challenging to effectively visualize randomly generated numerical sequences as concise sequential states. Consequently, after numerical generation, persistent instability arises in an uncontrollable state; thus, operations must be performed facing this fixed or non-fixed disordered state. To change this status quo, this research seeks controllable incremental or sequentially increasing states at the underlying algorithms of multiple numeral systems, embedding hidden or conditionally explicit increments to obtain new sequentially incremental calculation results.

## Objective

The problem addressed by this study is the controllable ordered variation of randomly changing large arrays, intended for scientific computing and algorithm design. It aims to conceal explicit calculations of increments while converting complex computational algorithms into simpler ones, allowing the hidden increments to be restored when needed.

## Method

The design of this implicit incremental algorithm for irrational numbers encompasses complex mathematical theories. Using irrational numbers such as Pi, the natural constant, and square roots as the basis for numerical random variation (and in non-fixed random operations), it establishes a secondary operational base formula for fixation. Treating the results of unordered basic operations as a fixed numerical variation state for digit changes enables controllable incremental operations. The difference between values is changed into real-number markers ranging from 0 to 9, which are then superimposed or decremented to generate new values. These new values undergo further operations to realize a hidden fixed-bit formula that no longer manifests explicitly.

## Result

In the structured study of irrational numbers, applying structured operations to Pi revealed various possible states of change. Rather than calculating fixed random bits, it can be transformed into:

```
3.141592653589
3.141,733,1386,1975,2768
```

And further into:

```
3.141,(733-x0),(1386-x1),(1975-x2),(2768-x3)
```

Where X=33 (fixed value) or (non-fixed incremental value X=x0+xn).

By setting x for incremental or decremental changes, controllable variation of increments is achieved in scientific computing, further forming:

```
3.141,700,1353,1942,2735
```

or even reaching:

```
3.141,5,658,1247,2039 or 3.141,5,6,7,Xn.
```

Thus, the result of numerical bit expansion is no longer random variation based on magnitude differences. The setting of the x operation value can be directly fixed as a specific x operation value, recorded to restore the original data.

## Conclusion

This explicit-implicit operational mechanism transforms complex, lightweight-unfriendly disordered variations into orderly incremental changes, eliminating the need for full-volume computation. In scenarios requiring random value results, it reduces computational load, lowers difficulty, improves accuracy, shortens cycles, enhances efficiency, and even supports changes in data exchange by avoiding the propagation of complex full-volume data.

## Research Motivation and Purpose

The explicit increment of random large-array irrational numbers is two sides of the same coin as implicit decrement, much like temperature changes—there are theoretically set extremely low stable states and theoretically set extremely high unstable states. This state seems related to the uncontrollable nature of entropy increase, yet entropy increase must also follow the ordered structures within disorder, giving rise to uncontrollable variations.

**Example:** Manually generating random integer values: a1, a2, a3, a4, a5.

The explicit incremental algorithm structures these random values into:

```
a1, (a1 + a2 = b1), (b1 + a3 = b2), (b2 + a4 = b3), (b3 + a5 = b4).
```

This structured explicit algorithm turns any generated random integer values into an incremental array.

The implicit algorithm goes further by directly performing decremental assignments on b1, b2, b3, b4 to achieve controllable increment, evolving into equal-position decrement:

```
a1, (a1 + a2 = b1 - x1), (b1 + a3 = b2 - x2), (b2 + a4 = b3 - x3), (b3 + a5 = b4 - x4).
```

Ultimately manifesting as:

```
a1=1, 1x2, 2x3, 3x4, i+Xn = 1, 2, 3, 4, 5, 6.
```
